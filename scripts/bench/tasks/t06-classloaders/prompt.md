GOAL: Implement isolated class loading for block providers: one class loader per provider, one set of loaders per fabric instance, plugins cannot see engine internals and cannot shadow contract classes.

CONTEXT: Module `engine` (Kotlin, JDK 21, Gradle). `kotlin/engine/build.gradle.kts` already has `testImplementation(project(":testkit"))` (the testkit offers `TestJar.fromJavaSources(...)` and `TestPluginBuilder` to build plugin JARs in tests). Types you use: `cringle.contract.BlockProvider`, `cringle.packaging.PluginManifest` (fields `providers: List<String>` = provider class names, `libs: List<String>` = JAR paths relative to the unpacked plugin directory). Every source file starts with `// SPDX-License-Identifier: Apache-2.0`; public API has KDoc.

FILES (touch only these):
- create `kotlin/engine/src/main/kotlin/cringle/engine/classloading/ClassLoaders.kt` (package `cringle.engine.classloading`)
- create `kotlin/engine/src/test/kotlin/cringle/engine/classloading/ClassLoadingTest.kt`

SPEC: public API of `ClassLoaders.kt`:
1. `class ProviderLoadException(val providerId: String, val className: String?, message: String, cause: Throwable? = null) : RuntimeException("provider '$providerId'" + (className?.let { " ($it)" } ?: "") + ": $message", cause)`.
2. `class ContractClassLoader(private val delegate: ClassLoader = ContractClassLoader::class.java.classLoader, val sharedPrefixes: List<String> = DEFAULT_SHARED_PREFIXES) : ClassLoader(getPlatformClassLoader())`: the narrow parent of all provider loaders. `fun isShared(name: String): Boolean` = name starts with one of `sharedPrefixes`. `loadClass(name, resolve)`: shared classes are taken from `delegate` (call `resolveClass` if `resolve`); every other class goes to `super` (so only JDK platform classes are found; engine classes and test libraries give `ClassNotFoundException`). `getResource(name)`: for `.class` resources of shared classes ask `delegate`, otherwise `super`. Companion: `val DEFAULT_SHARED_PREFIXES = listOf("cringle.contract.", "kotlin.", "kotlinx.coroutines.")`.
3. `class ProviderClassLoader(jars: List<Path>, private val contract: ContractClassLoader) : URLClassLoader(<jar URLs>, contract)`: child-first. `loadClass` runs `synchronized(getClassLoadingLock(name))`: return an already loaded class; shared classes and names starting with `java.` come from `contract`; every other class is first searched in the plugin's own JARs with `findClass`, and only if not found asked from `contract`. A class with the name of a shared class in a plugin JAR never replaces the shared one. `getResource` returns the own resource first, else `contract.getResource`; `getResources` returns own resources followed by `contract.getResources`.
4. `class FabricClassLoaders(private val contract: ContractClassLoader) : AutoCloseable`: all loaders of one fabric instance. `@Synchronized fun loaderFor(providerId: String, jars: List<Path>): ProviderClassLoader` creates the loader on first use (later calls ignore `jars`); throws `IllegalStateException("class loaders of this fabric are closed")` after `close()`. `fun openProviders(providerId: String, pluginRoot: Path, manifest: PluginManifest): List<BlockProvider>`: resolves every entry of `manifest.libs` against the normalised absolute `pluginRoot`; an entry outside the root fails with `ProviderLoadException(providerId, null, "jar '$entry' is outside the plugin directory")`, a missing file with `"jar '$entry' does not exist"`; then instantiates every class of `manifest.providers` through the loader of `providerId`: class not found -> message `"class not found in the plugin's JARs"`; `LinkageError` -> `"class cannot be linked: ${e.message}"`; not a `BlockProvider` -> `"does not implement cringle.contract.BlockProvider"`; no public no-argument constructor -> `"needs a public no-argument constructor"`; any other reflection failure -> `"cannot be instantiated: ${e.cause ?: e}"` (all as `ProviderLoadException(providerId, className, ..., cause)`). `@Synchronized override fun close()`: marks closed, closes every loader (continue after an `IOException`, rethrow the first one at the end), clears the map; safe to call more than once. After close the loaders and their classes must be garbage collectable (keep no references).
   Document the cost: every fabric instance loads its own copy of every provider class and library.

TESTS: create `ClassLoadingTest` (JUnit 5). At least: (a) `ContractClassLoader` shows the contract, kotlin and JDK classes (identical `Class` objects as in the test) and hides `cringle.packaging.Version` and `org.junit.jupiter.api.Test` (`ClassNotFoundException`); (b) `FabricClassLoaders.loaderFor` returns the same loader for the same provider id and different loaders for different ids; (c) after `close()`, `loaderFor` throws `IllegalStateException` and a second `close()` is fine; (d) `openProviders` with a manifest naming a missing class fails with a `ProviderLoadException` whose message contains `class not found`; (e) two providers with different versions of the same library JAR (build them with `TestJar.fromJavaSources` and `TestPluginBuilder`) see different library versions.

CHECK: `./gradlew :engine:test --tests 'cringle.engine.classloading.*' -q --console=plain` must pass.

OUT OF SCOPE: wiring the loaders into the engine or fabric start, other modules, documentation.
