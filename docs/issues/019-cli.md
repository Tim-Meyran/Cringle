# 019 – CLI

## Context
The CLI talks exclusively to the ManagementServer.

## Scope
- Module `cli` producing a `cringle` executable (script plus fat JAR or native image if practical).
- Commands: machines/daemons, engines (create, start, stop, list, status), remote routers (add, trust, revoke), repository (publish, list), logs, and later deploy (once 017 lands).
- Connection profile (ManagementServer address, client certificate, user token) in `~/.cringle/cli.json`; `cringle login` stores a token; user and token management commands (issue 022).
- Human-readable and `--json` output.

## Out of scope
Interactive shell, WebUI.

## Acceptance criteria
- [ ] Each command has tests against a test ManagementServer.
- [ ] `cringle --help` documents all commands.
